# 日本史○×：追加問題の校閲とジャンル付け

作成ルールは `content-work/nihonshi/add/BRIEF.md`。あなたは作成者とは別の校閲担当。担当論点ごとに次の3つをする。

## 1. 追加問題の校閲（`content-work/nihonshi/add/<分野>__<論点>.txt`、1行 `lv|a|s|e|m|y`）
- 1問ずつ事実を確かめる（山川『詳説日本史』水準の定説）。年代・人物・制度名・場所・数値・順序
- ○×が一意に決まるか。×は入れ替えが1か所で、解説の「誤り：〜。正しくは〜。」が正しいか
- 間違いは直す。直せない・学説が割れる・あいまいな問題は行ごと消す
- 解説の水増し・定型句は中身のある文に書き直す（60〜150字）。覚え方 10〜30字
- 同じ論点の既存問題（`add/existing/<分野>__<論点>.txt`）や追加分どうしで、同じ事実を同じ角度で問う重複は消す
- 同じ事実を○と×で対にした問題（片方の文を入れ替えただけ）は、どちらか一方だけ残す
- lv が水準（BRIEF.md）に合っているか。合わなければ lv を直す
- MARCH・早慶の過去問（`add/past-ref.txt`）の出題の細かさを目安にする

## 2. ジャンルとキーワード付け
- 各論点のジャンル一覧は `src/data/nihonshi-config.json` の `genres["分野|論点"]`。この中から必ず1つ選ぶ（一覧にない名前は使わない）
- キーワード w：その問題を調べるための語を1つ（解説に Wikipedia・YouTube のリンクとして出る）。**日本語版 Wikipedia の記事名になっている語**（人物・事件・制度・史料・作品・遺跡の正式名。例：墾田永年私財法、長屋王、承久の乱）。×の問題は、正しい内容の側の語を選ぶ。年号だけ・一般語（政治、経済）は不可
- 追加問題：各行の末尾に7列目ジャンル・8列目キーワードを足す → `lv|a|s|e|m|y|g|w`（y が空でも `||g|w` のように列を保つ）
- 既存問題：`src/data/nihonshi-ox.json` のうち担当論点の問題すべてに、`content-work/nihonshi/add/tags/<分野>__<論点>.txt` を作って `ref|ジャンル|キーワード` を1行ずつ書く

## 3. 記録
- `content-work/nihonshi/add/check/<分野>__<論点>.md` に、直した問題・消した問題（理由つき）を短く書く
- 書き終えたら python3 で：各行が8列か、ジャンルが一覧にあるか、×の割合（40〜60%）、×の解説が「誤り」で始まるか、を確かめる
- git 操作はしない。担当外のファイルは触らない
