## 3. App Store Connect 入力案（下書き）

名前は「総合アプリ名」が未決定のため2案。どちらでも説明文はほぼ同じ。

| 項目 | 案A（宅建単体） | 案B（総合アプリ） |
|---|---|---|
| 名前（30字以内） | 宅建 10分模試 | 10分模試 - 宅建・世界史・日本史 |
| サブタイトル（30字以内） | 本試験と同じ分野比率で毎日10問 | 10問10分で毎日できる模試 |
| カテゴリ | 教育（サブ：参考） | 教育（サブ：参考） |

**プロモーションテキスト（170字以内）**
毎日10問・10分。本試験と同じ分野比率で出題し、5回で本試験1回分。間違えた論点は解説と確認例題3問でその場で復習できます。

**説明文**
```
10問を10分で解く、すきま時間向けの模試アプリです。

■ 宅建
・本試験と同じ分野比率（業法・権利・法令・税その他）で10問を出題
・5回で50問＝本試験1回分。合計点で今の位置がわかります
・間違えた論点は「解説 → ひっかけ → 付随する論点 → 確認例題3問」で復習
・46論点の習熟度を色で表示（要復習／習得中／習得）
・音声読み上げで、問題を耳でも確認できます

■ 学習記録
・記録は端末内に保存します。アカウント登録は不要です

■ ご注意
・本アプリは個人学習用の非公式教材で、試験の実施機関とは関係ありません
・法令は改正されることがあります。最新の情報は公式資料でご確認ください
```
（「合格保証」「必ず受かる」などの表現は使わない）

**キーワード（100字以内・カンマ区切り）**
宅建,宅地建物取引士,宅建士,過去問,模試,一問一答,不動産,資格,勉強,問題集,業法,権利関係,法令上の制限

**年齢区分**：質問票はすべて「なし」→ 4+ になる見込み

**App のプライバシー（栄養成分ラベル）**：「データを収集していません」
- 理由：記録は端末内（AsyncStorage）のみ。分析・広告・クラッシュ収集ツールなし。課金は Apple が処理し、開発者はユーザー情報を受け取らない
- ※ 将来クラウド同期・ログインを入れたら回答を変える（メールアドレス・ユーザーID・学習データ）

**審査メモ（App Review への連絡事項）**
```
ログイン不要です。起動後すぐ「模試を始める」から10問の模試を体験できます。
App内課金（非消耗型）で各試験の全問題が解除されます。「購入を復元」はホーム画面の下部にあります。
問題は過去の試験の論点をもとにした学習用の非公式教材です。
```

## 4. 審査で落ちやすい点（このアプリでの対策）

| ガイドライン | 内容 | 対策 |
|---|---|---|
| 3.1.1 | デジタルコンテンツの解除は App内課金のみ。外部決済への誘導は不可 | 課金は IAP（StoreKit）で実装 |
| 3.1.1 | 非消耗型には「購入を復元」が必須 | ホームに復元ボタン |
| 4.2 | Webを包んだだけのアプリは却下 | ネイティブ実装済み（Expo / RN） |
| 2.1 | 審査時に未完成・クラッシュがあると却下 | TestFlight で全画面を確認してから提出 |
| 5.1.1 | ログインを入れるならアプリ内でアカウント削除が必要 | 初版はログインなし |
| 5.2 | 他者の権利物（過去問・参考書の文章）の無断利用 | 実施機関の回答と専門家確認を待ってから有料化 |
| 1.4 / 2.3 | 説明文と実際の機能の不一致、誇大表現 | 説明文は実装済み機能のみ。合格保証の表現なし |
