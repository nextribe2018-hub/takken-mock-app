宅建10分模試 プライバシーポリシー

株式会社iCurate（以下「当社」）は、iPhone アプリ「宅建10分模試」（以下「本アプリ」）での利用者の情報の扱いを、次のとおり定めます。本アプリはアカウント登録なしで使え、利用者の個人情報を当社のサーバーへ送る仕組みを持っていません。

1. 取得する情報

本アプリは、氏名、メールアドレス、電話番号、位置情報、端末の識別子、連絡先などの個人情報を取得しません。

2. 端末の中に保存する情報

解答の記録、正答率、模試の履歴、設定（音声読み上げの有無など）、全問解放の購入状態は、利用者の端末の中だけに保存します。これらの情報が当社に送られることはありません。本アプリを削除すると、これらの情報も削除されます。

3. アプリ内課金

全問解放の購入と支払いの手続きは、Apple Inc. の App Store が行います。当社は、クレジットカード番号など支払いに関する情報を受け取りません。購入済みかどうかの確認と「購入を復元」には、Apple が提供する仕組みを使います。

4. 解析ツール・広告

本アプリは、利用状況の解析ツール、広告、トラッキング（他社のアプリやウェブサイトをまたいだ追跡）を使用していません。

5. 第三者への提供

当社は本アプリを通じて個人情報を取得しないため、第三者に提供することはありません。

6. お問い合わせで受け取る情報

利用者がメールで当社に問い合わせた場合、当社はメールアドレスと問い合わせの内容を受け取ります。これらは回答と本アプリの改善のためだけに使い、法令で認められる場合を除き、第三者に提供しません。

7. このポリシーの変更

本アプリの機能の追加などに合わせて、このポリシーを変更することがあります。変更した場合は、このページで内容と日付をお知らせします。
