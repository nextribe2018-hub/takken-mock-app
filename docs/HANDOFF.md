## 5. データ仕様

### 問題（bank.json の1件）

```json
{"f":"業法","t":"免許","ref":"R06-38-1","s":"問題文","a":0,"e":"解説","m":"覚え方"}
```

| キー | 意味 |
|---|---|
| f | 分野：`業法`／`権利`／`法令`／`税他` |
| t | 論点名（46種） |
| ref | 出典「年度-問-肢」（例 R06-38-1、R03s＝12月試験、H30＝平成30年）。`確認` は自作の確認問題 |
| s | 問題文（○×で答える1文） |
| a | 正解 1＝○、0＝× |
| e | 解説（根拠条文つき） |
| m | 覚え方（短いフレーズ） |

- 問題の安定キー：`f|t|ref`（同じ組み合わせが重複したら `#2`, `#3`…）。学習記録はこのキーで保存するので、**問題文を直してもキーは変えない**こと。

### 解説（lessons.json）

キーは `分野|論点`（例 `業法|免許`）。値は `{pts: 要点[], traps: ひっかけ[], rel: 付随論点キー[], bridge: つなぎ文, sys: 体系解説}`。

`sys`（2026-10-07追加）＝間違えた論点を体系的に復習するための図表データ：
`{overview: 位置づけ, tree: [{h: 大項目, items: 小項目[]}]（体系図）, flow: {title, steps[]} | null（流れ図）, tables: [{title, head[], rows[][]}]（比較表）}`
- 解説は2段構成（2026-10-07 本人要望「長すぎる→間違えた範囲に絞り、広げる部分はリンクで」）
  - 1段目（復習画面）：間違えた問題 → 間違えた範囲の解説（体系図の該当1枝 `relatedBranch()`、関係する表の行だけ最大4行 `relatedRows()`、関係するひっかけ最大2件 `relatedTraps()`）→「体系的に広げる」（全項目チップ・体系ページへのリンク・つながる論点リンク）→ 確認例題3問
  - 2段目（体系ページ、Screen `deep`）：全体像ツリー（押した項目へスクロール＆枠で強調）→ 流れ図 → 比較表（全行）→ 要点・ひっかけ → つながる論点（さらに別論点の体系ページへ。パンくず表示）→「復習に戻る」
- 2026年4月1日時点の法令で別担当が検証済み（区分所有法改正、不動産取得税の免税点16万／66万／34万円、法定利率3%、重説の追加事項 等を反映）
- 本文で断定せず未記載にしている事項（今後追記候補）：拘禁刑導入前の刑の経過措置、改正区分所有法の定足数の規約緩和と60条の決議要件、開発許可のレッドゾーン範囲、2025年建基法改正の構造規定、盛土規制の定期報告・完了検査期限、印紙税の具体税額、買換え特例の細目、鑑定評価の細目、機構の買取条件、景品の上限額・規約の最新文言

### 学習記録（Progress）

```ts
{ v: 2, hist: { [問題キー]: {n: 解いた回数, c: 正解数, last: 1|0} },
  set: { round: 0-4, scores: number[] }, log: [{at, round, score, sec}], voice: boolean }
```

- Web版のサーバー保存先：アーティファクトDBの `data/users/<uid>/progress`（同じ形。`voice` はWeb版では端末側）
- Web版の書き出し形式：`"TKM1:" + base64(UTF-8 JSON {hist,set,log})` → アプリ版でも同じ形式で読み込めるようにすると、Web版の記録をアプリへ移せる

| キー | 意味 |
|---|---|
| id | 安定キー（数値）。変えない・使い回さない |

## 6. ロジック仕様（変えるときは本人に確認）

| 項目 | 仕様 |
|---|---|
| 1回の構成 | 10問・制限10分（600秒）。経過時間は開始時刻から計算 |

```bash
npm test              # ロジックテスト（比率・重複なし・5回で一周・復習・全論点に解説）
npm run typecheck     # 型チェック
python3 web/build.py  # Web版を再生成
```

- `npx expo install` はネットワーク制限のある環境では失敗することがある。その場合は `node -e "console.log(require('expo/bundledNativeModules.json')['<パッケージ名>'])"` で対応バージョンを調べて `npm install <pkg>@<ver>` する
- Web表示（react-native-web）も入っているので、`npx expo export --platform web` で画面確認ができる
- Web版HTMLをローカルで開くときは `<meta charset="utf-8">` を付けないと文字化けして動かない（公開時はプラットフォームが付ける）

## 9. 権利・表現の注意

- 法律の条文・知識そのものは著作権で保護されない（著作権法13条）。参考書の文章・図表・構成をそのまま写すのは不可
- 過去問本文の扱いは実施機関の回答を待つ。回答次第で、出典表記の仕方や問題文の書き換えを判断
- 慶應義塾大学の試験問題公開ページには「公開された入試問題を二次的に利用する場合は、改めて著作権許諾処理を閲覧者ご自身の責任において行う」とある。慶應の問題集は設問文・リード文・史料文を使わず、問われた知識だけを使って問題文と選択肢を独自に作成した（作成後に試験の文面との近さも点検して言い換え済み）。**有料アプリに入れる前に専門家の確認が必要**
- 立教・慶應とも「公式教材ではない」旨をフッター（Web版）に表示している。アプリ版でも同じ表示を入れる
- 宣伝やストア説明文で「合格保証」などの誇大表現は使わない（景品表示法）
- 担当者（Claude）は弁護士ではないので、権利の最終判断は専門家に確認
