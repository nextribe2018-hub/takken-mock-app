# 日本史○×10分模試（大学入試）仕様

2026-11-28 本人依頼：宅建10分模試と同じ仕様で、大学入試の日本史。日東駒専・MARCH・早慶の3水準それぞれの合格判定を出す。
決定：○×形式／約1,500問／Web版とアプリを同時に作る。

## 1. 全体
- 試験 id：`nihonshi-ox`、名前「日本史 10分模試」、group「大学入試」、format `ox`
- 1回10問・10分。5回で50問＝入試1回分。1問ごとに正誤・解説・覚え方を即表示（宅建と同じ）
- 復習：間違えた論点ごとに「間違えた問題 → 解説（要点・ひっかけ）→ 付随論点 → 確認例題3問」。体系ページ（全体像・年表・比較表）も宅建と同じ

## 3. 水準（lv）
| lv | 水準 | 目安 |

| 1 | 日東駒専 | 教科書の太字・基本用語・代表的な年代と人物。基本の因果関係 |
| 2 | MARCH | 教科書本文レベル。用語の区別（似た制度・事件の取り違え）、出来事の前後関係、史料の基本 |
| 3 | 早慶 | 教科書の脚注・図版キャプション・史料の読解、細かい年代・数値、正誤の細部（主体・場所・順序の入れ替え） |

- 各論点で lv1:lv2:lv3 ≒ 4:4:3 を目安。1回10問は lv1 4・lv2 4・lv3 2 を目標に選ぶ（足りなければ近い水準で補う）

## 5. 問題データ `src/data/nihonshi-ox.json`（配列）

```json
{"f":"古代","t":"律令国家の成立","ref":"KO-0123","lv":2,"s":"○×で答える1文","a":1,"e":"解説（なぜ○/×か。×なら正しい内容を明記）","m":"覚え方（短い）","y":701}
```

| キー | 意味 |
|---|---|
| f／t | 分野／論点（上の表の文字列と完全一致） |
| ref | 安定キーの一部。分野の頭文字＋連番：古代 KO-、中世 CH-、近世 KS-、近代 KD-、現代 GD-、文化 BK-（例 KO-0001）。**一度振ったら変えない・使い回さない** |
| lv | 1／2／3（上の水準） |
| s | 問題文。1文で○か×が一意に決まること。「〜である。」の断定文。否定文（〜ではない）は避ける |
| a | 1＝○、0＝×。○と×はおよそ半々（各論点で ×が40〜60%） |
| e | 解説 60〜150字。×の問題は「誤り：〜。正しくは〜」の形で、どこが違うかを示す |
| m | 覚え方 10〜30字（語呂・対比・キーワード） |
| y | 関係する年（西暦、紀元前はマイナス）。年が決まらない文化・制度の説明などは省略可 |

- 安定キーは `f|t|ref`（宅建と同じ）
- ×の作り方：主体（人物）・年代・場所・制度名・順序・数値の1か所だけを入れ替える。入れ替えた誤りは実在の紛らわしい用語（例：墾田永年私財法↔三世一身法）を使う
- 問題文は教科書・参考書・過去問の文章を写さず、自分の言葉で書く。年代・人名・用語は教科書（山川『詳説日本史』水準）の定説に従い、学説が分かれるものは出題しない

## 6. 解説データ `src/data/nihonshi-lessons.json`

キー `分野|論点`、値は宅建の lessons.json と同じ形：
`{pts: 要点[]（5〜8）, traps: ひっかけ[]（3〜6）, rel: 付随論点キー[]（2〜4、"分野|論点"）, bridge: つなぎ文, sys: {overview, tree: [{h, items[]}], flow: {title, steps[]}|null（年表・流れ）, tables: [{title, head[], rows[][]}]}}`

## 7. 合格の見込み（3水準）

- 水準別の○×正答率（直近10問ベース、宅建と同じ r10 の考え方を水準別に）→ `toExam(p, k)` で4択に換算（慎重 k=0／標準 k=0.5／消去法 k=1、見出しは標準）
- 各大学群の入試を、水準の混ぜ方と合格ラインでモデル化（仮の値。本人と調整）：

| 大学群 | lv1 | lv2 | lv3 | 合格ライン（4択換算の得点率） |
|---|---|---|---|---|
| 日東駒専 | 60% | 35% | 5% | 60〜70%（等確率） |
| MARCH | 25% | 50% | 25% | 65〜75% |
| 早慶 | 10% | 40% | 50% | 70〜80% |

- 50問の得点を3,000回シミュレーション（正答率の不確かさはベータ分布、乱数は固定シード）→ 3つの合格確率を並べて表示。30回答未満は非表示
- 分野別の予想得点・「いちばん伸ばせる分野」も宅建と同じ
