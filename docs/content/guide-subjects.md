# 科目別の作り方

## 日本史・世界史・地理（100問、check は history）
- 過去問で問われた知識を4〜5択に。記述・論述問題も、正解になる用語や論点を選択式にすれば使える。
- 正誤判定型（正しくないものはどれか）、年代整序型（ア〜エを古い順に）、ⅰ・ⅱの正誤組合せも、その大学の形式に合わせて混ぜる。
- past はできるだけ多く（目安60〜70問）、残りを plan。
- 地理は y を付けにくい問題が多いので、地理だけは lang で検査し y を付けない。

## 英語（60問、check は lang）
- 分野の例：会話文、文法・語法、語彙・イディオム、整序（語句の並べ替え）、長文読解。その大学の大問構成に合わせて決める。
- 文法・語法・語彙：過去問で問われた文法事項・語法・語句（正解の語）を、新しい自作の例文で問う（past）。例文は試験の文を写さない。
- 整序：自作の英文で「並べ替えたとき○番目に来る語」を4択で。
- 会話文：自作の短い会話を p に入れる。
- 長文読解：自作の英文（120〜300語）を p に入れ、内容一致・空所補充・語の意味などを問う。1つの本文から最大3問まで（各問に本文をコピー）。本文のテーマは過去問と同系統（例：社会・科学・文化）でよいが、内容は自作。
- q（問いの指示）は日本語、c は英語でよい。解説は日本語で、根拠となる本文の箇所や文法の理由を示す。

## 国語（60問、check は lang）
- 分野の例：現代文（評論）、現代文（小説）、漢字・語彙、古文、漢文、文学史。その大学の出題範囲に合わせる（漢文の出ない大学では漢文を作らない）。
- 現代文：本文はすべて自作（評論は300〜800字、小説風の文章も可）。内容一致・傍線部の理由・語句の意味・空所補充を問う。
- 漢字・語彙・慣用句・文学史：過去問で問われた語や知識を、新しい問いの形で（past）。
- 古文・漢文：著作権の切れた古典の原文を p に入れてよい（作品名を明記）。語の意味・文法（助動詞・敬語）・解釈・内容を問う。過去問と同じ作品を使ってもよいが、設問と選択肢は自作。現代語訳は自作。

## 数学（60問、check は lang）
- 小問形式で「答えの値」や「正しい式」を4択に。誤答は典型的なミス（符号・係数・場合分けの漏れ）の値。
- 必ず Python（sympy 可）で答えを計算・検算する。
- 数式は q と c に普通の文字で書く（例：x^2 + 3x - 4、√2、π、∫ は使ってよい）。読みやすさを優先。
- 過去問の大問は、誘導の一つ一つを小問として使える（past）。

## 物理・化学・生物（60問、check は lang）
- 知識問題と、条件から値を求める小問を混ぜる。数値は Python で確かめる。有効数字・単位を明記。
- 過去問の大問の設問を、図がなくても成り立つ小問に分解して使う（past）。

## 税理士（100問、check は lang）
- 法令は「令和8年4月3日現在施行」を基準にする（第76回・2026年8月試験の公告と同じ。2027年試験の基準日は未公表）。改正が多い数値（税率・限度額・控除額）は、条文（e-Gov 法令検索）か国税庁タックスアンサーで確かめる（WebFetch 可）。確かめられない数値は使わない。
- 理論：「正しいものはどれか／誤っているものはどれか」の4択。条文・通達・会計基準の趣旨を問う。
- 計算：論点ごとの小問。条件を p に書き、答えの金額を4択で。Python で計算して確かめる。
- 過去問（国税庁公開）の論点を使った問題を past とする（公式解答はないので、自分で確実に解けるものだけ）。

## 資格試験（暗記型の国家試験・民間資格）（100問、check は lang）
- 対象例：ITパスポート、基本情報（科目A）、危険物乙4、第二種電気工事士（学科）、衛生管理者、登録販売者、FP、簿記、管理業務主任者、マンション管理士、賃貸不動産経営管理士、社労士、行政書士。
- 形式は本試験に合わせる（多くは4〜5択。FP3級のような○×・3択の試験は、4択に作り直すか、選択肢が2〜3個のときは「正しい／誤り」＋紛らわしい2肢を足して4択にする）。
- 分野は試験の出題範囲（シラバス・出題基準）の大項目に合わせて5〜6個。
- 法令・制度・基準（税制、社会保険、電気設備技術基準、危険物の規制、医薬品の分類など）は、基準日を決めて問題文か解説に明記する（例「2026年4月1日現在の法令」）。数値は e-Gov・所管官庁・実施団体の公式資料で確かめる。確かめられない数値は使わない。
- 過去問：実施団体が公表している問題・解答・公表問題を素材にする（利用条件を必ず確認し、素材フォルダの index.md に原文で記録する）。問われた知識を使い、問題文・選択肢は自作する。
- 図・写真・回路図・構造式が必要な問題は、文章だけで答えが一つに決まる場合だけ使う。
- 医薬品・医療・安全にかかわる内容は、誤りが実害につながるので特に厳しく確認し、不確かなものは出さない。

## 高校受験・中学受験（社会100問、理科・英語・国語は60問。社会は check history、ほかは lang）
- 範囲は学習指導要領と教科書の標準的な内容（高校受験＝中学校、中学受験＝小学校＋中学受験で一般的な発展事項）。
- 入試問題は都道府県・各中学校に権利があるので、過去問の文面は使わない。全国の入試で頻出の知識を、自作の問題で問う（k は plan、ref は「想定問題」。公式に公開され利用条件が明確な素材を使った場合だけ past）。
- 対象学年に合わせた言葉づかい（中学受験は小学5〜6年生が読める文。難しい漢字は避けるか（よみ）を添える）。
- 社会は年号 y を付ける（地理・公民で年がないものは、その分野だけ lang で別ファイルにしてもよい）。時事は基準日を明記する。
- 理科は知識問題を中心に、計算は小問にして Python で検算する。
- 英語は単語・熟語・文法・会話の短い4択。国語は漢字・語句・慣用句・ことわざ・文法（古文は高校受験のみ）。
